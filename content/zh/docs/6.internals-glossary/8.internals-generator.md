# Generator 类

---

- 源码: **[generator/generator.js](https://github.com/nuxt/nuxt/blob/2.x-dev/packages/generator/src/generator.js)**

## 钩子

`generate:` 钩子：

| 钩子 | 参数 | 时机 |
| ----------------------- | ---------------------------- | -------------------------------------------------------------------------------- |
| `generate:before`       | (generator, generateOptions) | 生成前的钩子 |
| `generate:distRemoved`  | (generator)                  | 构建目标文件夹被删除时的钩子 |
| `generate:distCopied`   | (generator)                  | 静态文件和构建文件被复制时的钩子 |
| `generate:route`        | ({ route, setPayload })      | 页面生成前的钩子，适用于动态 payload，参见 [#7422](https://github.com/nuxt/nuxt/pull/7422)，Nuxt v2.13 及以上可用 |
| `generate:page`         | ({ route, path, html })      | 用户更新生成后的路径和 HTML 时的钩子 |
| `generate:routeCreated` | ({ route, path, errors })    | 生成的页面保存成功时的钩子 |
| `generate:extendRoutes` | (routes)                     | 用户更新要生成的路由时的钩子 |
| `generate:routeFailed`  | ({ route, errors })          | 生成的页面保存失败时的钩子 |
| `generate:done`         | (generator, errors)          | 生成完成时的钩子 |
