# Nuxt 类

核心容器，用于使所有模块和类能够相互通信。所有模块都可以使用 `this.nuxt` 访问 Nuxt 实例。

---

- 源码: **[core/nuxt.js](https://github.com/nuxt/nuxt/blob/2.x-dev/packages/core/src/nuxt.js)**

## 钩子

可以在特定生命周期事件上注册钩子。

```js
nuxt.hook('ready', async nuxt => {
  // 在此处编写代码
})
```

| 插件 | 参数 | 时机 |
| -------- | ---------------------- | ------------------------------------------------------------------------------ |
| `ready`  | (nuxt)                 | Nuxt（`ModuleContainer` 和 `Renderer`）准备就绪时 |
| `error`  | (error)                | 调用钩子时发生未处理错误时 |
| `close`  | (nuxt)                 | Nuxt 实例正常关闭时 |
| `listen` | (server, {host, port}) | Nuxt 内部服务器开始监听时（使用 `nuxt start` 或 `nuxt dev` 时触发） |
