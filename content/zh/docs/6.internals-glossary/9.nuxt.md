# 以编程方式使用 Nuxt

以编程方式使用 Nuxt，可以将其作为中间件使用，并可以自由创建用于渲染 Web 应用程序的自定义服务器。

---

有时你可能希望将 Nuxt 与自己的服务器以及中间件或 API 一起使用，这时可以以编程方式使用 Nuxt。

## Nuxt 构造函数

要查看可传递给 Nuxt 的选项列表，请参阅配置部分。

```js
const { loadNuxt, build } = require('nuxt')

// 检查是否需要以开发模式运行 Nuxt
const isDev = process.env.NODE_ENV !== 'production'

// 获取 Nuxt 实例
const nuxt = await loadNuxt(isDev ? 'dev' : 'start')

// 开发模式下启用实时构建和实时重载
if (isDev) {
  build(nuxt)
}

// 可以使用 `nuxt.render(req, res)` 或 `nuxt.renderRoute(route, context)`
```

可以参考 [nuxt-express](https://github.com/nuxt/express) 或 [adonuxt](https://github.com/nuxt/adonuxt) 快速入门。

### 调试日志

如果想显示 Nuxt 的日志，请在文件开头添加以下代码：

```js
process.env.DEBUG = 'nuxt:*'
```
