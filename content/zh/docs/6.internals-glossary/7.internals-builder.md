# Builder 类

---

- 源码: **[builder/builder.js](https://github.com/nuxt/nuxt/blob/2.x-dev/packages/builder/src/builder.js)**

## 钩子

可以在特定生命周期事件上注册钩子。

```js
// 添加构建钩子
this.nuxt.hook('build:done', (builder) => {
  ...
})
```

| 钩子 | 参数 | 时机 |
| ----------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| `build:before`          | (nuxt, buildOptions)                        | Nuxt 构建开始前 |
| `builder:prepared`      | (nuxt, buildOptions)                        | 构建目录创建时 |
| `builder:extendPlugins` | (plugins)                                   | 生成插件时 |
| `build:templates`       | ({ templatesFiles, templateVars, resolve }) | 生成 `.nuxt` 模板文件时 |
| `build:extendRoutes`    | (routes, resolve)                           | 生成路由时 |
| `webpack:config`        | (webpackConfigs)                            | 配置编译器之前 |
| `build:compile`         | ({ name, compiler })                        | webpack 编译之前（compiler 为 webpack `Compiler` 实例），universal 模式下会以 `'client'` 和 `'server'` 名称各调用一次。|
| `build:compiled`        | ({ name, compiler, stats })                 | webpack 构建完成时 |
| `build:done`            | (nuxt)                                      | Nuxt 构建完成时 |
