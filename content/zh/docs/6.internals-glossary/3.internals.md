# Nuxt 模块介绍

深入了解 Nuxt 内部机制

---

Nuxt 拥有完全模块化的架构，开发者可以使用灵活的 API 扩展 Nuxt Core 的任意部分。

如果你有兴趣开发自己的模块，请参阅[模块指南](/docs/directory-structure/modules)文档。

本节内容有助于熟悉 Nuxt 内部机制，在创建自己的模块时可作为参考。

## 打包与使用

Nuxt 默认导出所有类，导入方式如下：

```js
import { Nuxt, Builder, Utils } from 'nuxt'
```

## 通用模式

所有 Nuxt 类都持有对 `nuxt` 实例和选项的引用，因此在类之间始终有一致的 API 来访问 `options` 和 `nuxt`。

```js
class SomeClass {
  constructor(nuxt) {
    super()
    this.nuxt = nuxt
    this.options = nuxt.options
  }

  someFunction() {
    // 可以访问 `this.nuxt` 和 `this.options`
  }
}
```

类是_可插拔的_，因此需要在 nuxt 容器中注册插件以注册更多钩子。

```js
class FooClass {
  constructor(nuxt) {
    super()
    this.nuxt = nuxt
    this.options = nuxt.options

    this.nuxt.callHook('foo', this)
  }
}
```

可以像这样钩入 `foo` 模块：

```js
nuxt.hook('foo', foo => {
  // ...
})
```
