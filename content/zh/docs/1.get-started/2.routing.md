# 路由

大多数网站不止有一个页面，例如首页、关于页面、联系页面等。要显示这些页面，需要一个路由器。

## 自动生成路由

大多数网站不止有一个页面（例如首页、关于页面、联系页面等），要显示这些页面需要路由器。这就是 `vue-router` 的用武之地。在 Vue 应用中，需要设置配置文件（例如 `router.js`）并手动添加所有路由。Nuxt 根据 `pages` 目录中的 Vue 文件自动生成 `vue-router` 配置，也就是说不再需要编写路由配置！Nuxt 还会自动对所有路由进行代码分割。

换句话说，应用中实现路由所需做的就是在 `pages` 文件夹中创建 `.vue` 文件。

::alert{type="next"}
详情请参阅 [路由](/docs/features/file-system-routing)。
::

## 导航

要在应用的页面之间跳转，需要使用 [NuxtLink](/docs/features/nuxt-components#the-nuxtlink-component) 组件。该组件包含在 Nuxt 中，无需像其他组件一样导入。它类似于 HTML 的 `<a>` 标签，但使用 `to="/about"` 代替 `href="/about"`。如果之前使用过 `vue-router`，可以将 `<NuxtLink>` 视为 `<RouterLink>` 的替代品。

指向 `pages` 文件夹中 `index.vue` 的简单链接：

```html{}[pages/index.vue]
<template>
  <NuxtLink to="/">Home page</NuxtLink>
</template>
```

对于站内所有页面的链接，请使用 `<NuxtLink>`。如果有指向其他网站的链接，请使用 `<a>` 标签。示例如下：

```html{}[pages/index.vue]
<template>
  <main>
    <h1>Home page</h1>
    <NuxtLink to="/about">
      About (internal link that belongs to the Nuxt App)
    </NuxtLink>
    <a href="https://v2.nuxt.com">External Link to another page</a>
  </main>
</template>
```

::alert{type="next"}
详情请参阅 [NuxtLink 组件](/docs/features/nuxt-components#the-nuxtlink-component)。
