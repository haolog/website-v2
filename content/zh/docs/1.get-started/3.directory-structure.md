# 目录结构

默认的 Nuxt 应用结构旨在为大小应用提供良好的起点。您可以自由组织应用，并根据需要创建其他目录。

---

让我们创建项目中尚不存在的目录和文件：

```bash
mkdir components assets static
touch nuxt.config.js
```

这些是构建 Nuxt 应用时使用的主要目录和文件，下面将分别介绍。

::alert{type="info"}
创建这些名称的目录即可启用 Nuxt 项目的相应功能。
::

## 目录

### pages 目录

`pages` 目录包含应用的视图和路由。如前所述，Nuxt 读取此目录中的所有 `.vue` 文件并创建应用路由器。

::alert{type="next"}
了解更多关于 [pages 目录](/docs/directory-structure/pages)
::

### components 目录

`components` 目录存放所有要导入到页面中的 Vue.js 组件文件。

使用 Nuxt，可以将创建的组件自动导入到 `.vue` 文件中。将 components 设置为 true 后，Nuxt 会扫描并自动导入它们。

::alert{type="next"}
了解更多关于 [components 目录](/docs/directory-structure/components)
::

### assets 目录

`assets` 目录存放样式、图片、字体等未编译的资源。

::alert{type="next"}
了解更多关于 [assets 目录](/docs/directory-structure/assets)
::

### static 目录

`static` 目录直接映射到服务器根目录，包含必须保持文件名的文件（例如 `robots.txt`）_或_不太可能更改的文件（例如 favicon）。

::alert{type="next"}
了解更多关于 [static 目录](/docs/directory-structure/static)
::

### nuxt.config.js 文件

`nuxt.config.js` 文件是 Nuxt 配置的唯一入口。如果要添加模块或覆盖默认设置，请在此处进行更改。

::alert{type="next"}
了解更多关于 [nuxt.config.js 文件](/docs/directory-structure/nuxt-config)
::

### package.json 文件

`package.json` 文件包含应用的所有依赖项和脚本。

## 关于项目结构的更多信息

还有更多有用的目录和文件，包括 [content](/docs/directory-structure/content)、[layouts](/docs/directory-structure/layouts)、[middleware](/docs/directory-structure/middleware)、[modules](/docs/directory-structure/modules)、[plugins](/docs/directory-structure/plugins) 和 [store](/docs/directory-structure/store)。小型应用不需要这些，因此这里不作介绍。

::alert{type="next"}
要了解所有目录的详细信息，请参阅[目录结构文档](/docs/directory-structure/nuxt)。
::
