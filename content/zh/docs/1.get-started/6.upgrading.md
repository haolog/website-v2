# 升级

升级 Nuxt 很快，但比更新 package.json 更复杂

---

如果要升级到 Nuxt v2.14 并使用静态托管，需要在 nuxt.config.js 文件中添加 [`target:static`](/docs/features/deployment-targets#static-hosting) 以使 generate 命令正常工作。

```js{}[nuxt.config.js]
export default {
  target: 'static'
}
```

## 开始

1. 查看要升级版本的[发布说明](/releases)，确认该版本是否有额外说明。
2. 更新 `package.json` 文件中 `nuxt` 包的指定版本。

此步骤之后的操作取决于您使用 Yarn 还是 npm。_[Yarn](https://yarnpkg.com/en/docs/usage) 是编写了测试的开发工具，是使用 Nuxt 的推荐包管理器。_

## Yarn

3. 删除 `yarn.lock` 文件。
4. 删除 `node_modules` 目录。
5. 运行 `yarn` 命令。
6. 安装完成并测试后，考虑升级其他依赖项，可以使用 `yarn outdated` 命令。

## npm

3. 删除 `package-lock.json` 文件。
4. 删除 `node_modules` 目录。
5. 运行 `npm install` 命令。
6. 安装完成并测试后，考虑升级其他依赖项，可以使用 `npm outdated` 命令。
