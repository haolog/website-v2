# 渲染

## 服务端渲染站点与静态站点

**服务端渲染站点**在用户每次请求页面时都在服务器上渲染，因此需要一个能够为每个请求提供页面的服务器。

**静态站点**与服务端渲染应用非常相似，主要区别在于静态站点在构建时渲染，因此不需要服务器。从一个页面导航到另一个页面是在客户端完成的。

有关静态和服务器托管，请参阅[部署目标](/docs/features/deployment-targets)。

```js{}[nuxt.config.js]
export default {
  ssr: true // 默认值
}
```

::alert{type="info"}
默认情况下服务端渲染已启用，因此无需在 Nuxt 配置中添加 `ssr: true` 来启用服务端渲染。
::

## 仅客户端渲染

仅客户端渲染无法进行服务端渲染。客户端渲染是指使用 JavaScript 在浏览器中渲染内容，而不是从 HTML 获取所有内容，只获取基本的 HTML 文档和 JavaScript 文件，然后使用浏览器渲染站点的其余部分。要进行客户端渲染，请将 ssr 设置为 `false`。

```js{}[nuxt.config.js]
export default {
  ssr: false
}
```
