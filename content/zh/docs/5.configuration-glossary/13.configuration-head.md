# head 属性

Nuxt 允许在 `nuxt.config.js` 中使用 `head` 属性定义应用程序的所有默认 meta 信息

---

- 类型: `Object` 或 `Function`

```js{}[nuxt.config.js]
export default {
  head: {
    titleTemplate: '%s - Nuxt',
    meta: [
      { charset: 'utf-8' },
      { name: 'viewport', content: 'width=device-width, initial-scale=1' },

      // `hid` 用作唯一标识符，请勿使用 `vmid`，它不起作用
      { hid: 'description', name: 'description', content: 'Meta description' }
    ]
  }
}
```

有关 head 可用选项列表，请参阅 [vue-meta 文档](https://vue-meta.nuxtjs.org/api/#metainfo-properties)。

也可以将 `head` 用作组件中的函数，通过 `this` 访问组件数据（[详情请参阅此处](/docs/components-glossary/head)）。

::alert{type="info"}
为避免在子组件中使用时出现重复的 meta 标签，请使用 meta 元素的 `hid` 键设置唯一标识符（[详情请参阅此处](https://vue-meta.nuxtjs.org/api/#tagidkeyname)）。
::
