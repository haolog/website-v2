# Runtime config 属性

使用 RuntimeConfig 可以将动态配置和环境变量传递给 nuxt 上下文。有关更详细的用法，请参阅 [runtime config 文档](/docs/directory-structure/nuxt-config#runtimeconfig)。

---


## `publicRuntimeConfig`

- 类型: `Object`

此对象的值可以使用 `$config` 从**客户端和服务端**访问。

## `privateRuntimeConfig`

- 类型: `Object`

此对象的值只能使用 `$config` 从**服务端**访问，会覆盖服务端的 `publicRuntimeConfig`。
