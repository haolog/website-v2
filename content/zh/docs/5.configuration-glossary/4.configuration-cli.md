# cli 属性

Nuxt 允许自定义 CLI 配置。

---

## badgeMessages

- 类型: `Array`

向 CLI 横幅添加消息。

```js{}[nuxt.config.js]
cli: {
  badgeMessages: ['Hello World!']
}
```

![](/img/docs/cli-badge.png)

## bannerColor

- 类型: `String`
- 默认值: `'green'`

更改 CLI 横幅中 "Nuxt" 标题的颜色。

**可用颜色：**

`black`、`red`、`green`、`yellow`、`blue`、`magenta`、`cyan`、`white`、`gray`、`redBright`、`greenBright`、`yellowBright`、`blueBright`、`magentaBright`、`cyanBright`、`whiteBright`

```js{}[nuxt.config.js]
export default {
  cli: {
    bannerColor: 'yellow'
  }
}
```
