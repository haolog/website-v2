# vue.config 属性

Vue.config 的配置对象

---

- 类型: `Object`
- 默认值: `{ silent: !isDev, performance: isDev }`

> vue.config 属性为 `Vue.config` 提供直接配置的桥梁。

**示例**

```js{}[nuxt.config.js]
export default {
  vue: {
    config: {
      productionTip: true,
      devtools: false
    }
  }
}
```

此配置会生成以下 Vue.config：

```js
Vue.config.productionTip // true
Vue.config.devtools // false
Vue.config.silent // !isDev [默认值]
Vue.config.performance // isDev [默认值]
```

有关 `Vue.config` API 的详情，请参阅[官方 Vue 文档](https://v2.vuejs.org/v2/api/#Global-Config)。
