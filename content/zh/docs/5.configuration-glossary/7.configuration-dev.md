# dev 属性

定义是开发模式还是生产模式。

---

- 类型: `Boolean`
- 默认值: `true`

此属性会被 nuxt 命令覆盖：

- 使用 `nuxt` 命令时，`dev` 强制为 `true`
- 使用 `nuxt build`、`nuxt start` 和 `nuxt generate` 时，`dev` 强制为 `false`

此属性在[以编程方式使用 Nuxt](/docs/internals-glossary/nuxt) 时设置：

```js{}[nuxt.config.js]
export default {
  dev: process.env.NODE_ENV !== 'production'
}
```

```js{}[server.js]
const { Nuxt, Builder } = require('nuxt')
const app = require('express')()
const port = process.env.PORT || 3000

// 使用选项实例化 Nuxt
const config = require('./nuxt.config.js')
const nuxt = new Nuxt(config)
app.use(nuxt.render)

// 仅在开发模式下构建
if (config.dev) {
  new Builder(nuxt).build()
}

// 监听服务器
app.listen(port, '0.0.0.0').then(() => {
  console.log(`Server is listening on port: ${port}`)
})
```

```json{}[package.json]
{
  "scripts": {
    "dev": "node server.js",
    "build": "nuxt build",
    "start": "NODE_ENV=production node server.js"
  }
}
```
