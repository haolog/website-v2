# mode 属性

更改默认 nuxt 模式

---

- 类型: `string`
  - 默认值: `universal`
  - 可选值:
    - `'spa'`：不进行服务端渲染（仅客户端导航）
    - `'universal'`：同构应用程序（服务端渲染加客户端导航）

> 可以在 `nuxt.config.js` 中使用此选项更改默认 nuxt 模式

::alert{type="warning"}
已废弃：请使用 `ssr: false` 代替 `mode: spa`
::
