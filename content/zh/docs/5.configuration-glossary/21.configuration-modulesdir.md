# modulesDir 属性

为 Nuxt 应用程序定义模块目录

---

- 类型: `Array`
- 默认值: `['node_modules']`

> 用于设置模块目录以进行路径解析，例如 webpack 的 `resolveLoading`、`nodeExternals` 和 `postcss`。配置路径相对于 [options.rootDir](/docs/configuration-glossary/configuration-rootdir)（默认: `process.cwd()`）。

```js{}[nuxt.config.js]
export default {
  modulesDir: ['../../node_modules']
}
```

如果项目以 Yarn workspace 风格的 monorepo 组织，则可能需要此字段。
