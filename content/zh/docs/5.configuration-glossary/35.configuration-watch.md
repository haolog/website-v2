# watch 属性

watch 属性允许监听自定义文件以重启服务器。

---

- 类型: `Object`
- 默认值: `[]`

```js
watch: ['~/custom/*.js']
```

[chokidar](https://github.com/paulmillr/chokidar) 用于配置 watcher。有关 chokidar 模式选项的详情，请参阅 [chokidar API](https://github.com/paulmillr/chokidar#api)。
