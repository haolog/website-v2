# rootDir 属性

定义 Nuxt 应用程序的工作区

---

- 类型: `String`
- 默认值: `process.cwd()`

当向 nuxt 命令（nuxt start、nuxt build 等）传递参数时，此属性会被覆盖。例如，运行 `nuxt ./my-app/` 会将 `rootDir` 设置为当前/工作目录 `./my-app/` 的绝对路径。

除非[以编程方式使用 Nuxt](/docs/internals-glossary/nuxt)，否则通常不需要指定此选项。

::alert{type="info"}
为了[解析依赖](https://nodejs.org/api/modules.html#modules_all_together)，包含 `node_modules` 目录的包根目录和 `rootDir` 需要在同一目录树中。否则请参阅 [`srcDir` 选项](/docs/configuration-glossary/configuration-srcdir)了解不同目录结构的示例。
::
