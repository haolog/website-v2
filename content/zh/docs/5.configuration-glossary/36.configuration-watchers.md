# watchers 属性

nuxt.config.js 中的 watchers 属性允许覆盖 watcher 配置。

---

- 类型: `Object`
- 默认值: `{}`

## chokidar

- 类型: `Object`
- 默认值: `{}`

有关 chokidar 选项的详情，请参阅 [chokidar API](https://github.com/paulmillr/chokidar#api)。

## webpack

- 类型: `Object`
- 默认值:

```js
watchers: {
  webpack: {
    aggregateTimeout: 300,
    poll: 1000
  }
}
```

有关 webpack watchOptions 的详情，请参阅 [webpack 文档](https://webpack.js.org/configuration/watch/#watchoptions)。
