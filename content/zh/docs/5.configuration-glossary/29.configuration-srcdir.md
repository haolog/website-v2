# srcDir 属性

定义 Nuxt 应用程序的源目录。

---

- 类型: `String`
- 默认值: [rootDir 值](/docs/configuration-glossary/configuration-rootdir)

指定相对路径时，相对于 `rootDir`。

示例 1：前提条件：

```js{}[nuxt.config.js]
export default {
  srcDir: 'client/'
}
```

```js{}[package.json]
  "script": {
    "dev": "yarn nuxt"
  }
```

适用于以下文件夹结构（注意 nuxt.config 在 app 目录中）：

```bash
-| app/
---| node_modules/
---| nuxt.config.js
---| package.json
---| client/
------| assets/
------| components/
------| layouts/
------| middleware/
------| pages/
------| plugins/
------| static/
------| store/
```

示例 2：

也可以将 nuxt.config 移到 `client` 文件夹，此时只需将 `client` 指定为 `rootDir`，`srcDir` 可以为空：

前提条件：

```js{}[nuxt.config.js]
export default {
  srcDir: '' // 或直接删除
}
```

```js{}[package.json]
  "script": {
    "dev": "yarn nuxt client" // 将 client 设置为 rootDir
  }
```

适用于以下文件夹结构（注意 nuxt.config 在 client 目录中）：

```bash
-| app/
---| node_modules/
---| package.json
---| client/
------| nuxt.config.js
------| assets/
------| components/
------| layouts/
------| middleware/
------| pages/
------| plugins/
------| static/
------| store/
```
