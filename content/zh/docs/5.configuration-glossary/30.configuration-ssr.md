# ssr 属性

更改默认 nuxt ssr 的值。

---

- 类型: `boolean`
- 默认值: `true`
- 可选值:
  - `true`：启用服务端渲染
  - `false`：不进行服务端渲染（仅客户端渲染）

> **只想进行客户端渲染时**可以将此选项设为 `false`

```js{}[nuxt.config.js]
export default {
  ssr: false // 禁用服务端渲染
}
```

::alert{type="next"}
以前使用 `mode` 属性来启用或禁用服务端渲染，[`mode` 文档](/docs/configuration-glossary/configuration-mode)在此处。
::
