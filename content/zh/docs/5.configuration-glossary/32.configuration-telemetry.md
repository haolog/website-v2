# telemetry 属性

Nuxt 收集关于一般使用情况的匿名遥测数据，以便准确了解所有用户中 Nuxt 功能的使用情况和自定义情况。

---

## telemetry 属性

> Nuxt Telemetry 在 Nuxt v2.13.0 中引入，用于收集关于一般使用情况的匿名遥测数据，以便准确了解所有用户中 Nuxt 功能的使用情况和自定义情况。

- 类型: `Boolean`
- 默认值基于用户偏好

## 为什么收集遥测数据

Nuxt 自[首次发布](https://github.com/nuxt/nuxt/releases/tag/v0.2.0)（2016/11/7）以来已大幅成长，我们一直在倾听[社区反馈](https://github.com/nuxt/nuxt/issues)以改进它。

但这个手动过程只能从用户子集收集反馈，这些反馈来自需要花时间填写的 issue 模板，而且不同人的需求和用例可能不同。

Nuxt Telemetry 收集**关于一般使用情况的匿名遥测数据**，有助于准确了解所有用户中功能的使用情况和自定义情况。这些数据有助于更好地衡量和理解 Nuxt 在全球的使用方式以及改进点（DX 和性能）及其相关性。

收集的事件包括：

- 命令调用（nuxt dev、nuxt build 等）
- Nuxt 和 Node.js 版本
- 一般机器信息（MacOS/Linux/Windows 以及是否在 CI 中运行命令、ci 名称）
- webpack 构建时间和应用程序平均大小，以及生成统计信息（使用 nuxt generate 时）
- 项目的公共依赖项（Nuxt 模块）

代码是开源的，可在 https://github.com/nuxt/telemetry 获取。

## 退出

有几种方式可以禁用 [Nuxt Telemetry](https://github.com/nuxt/telemetry)：

1. 使用 `npx nuxt telemetry disable`

```bash
npx nuxt telemetry [status|enable|disable] [-g,--global] [dir]
```

2. 使用环境变量

```bash
NUXT_TELEMETRY_DISABLED=1
```

3. 在 `nuxt.config.js` 中设置 `telemetry: false`：

```js{}[nuxt.config.js]
export default {
  telemetry: false
}
```

有关 Nuxt Telemetry 和发送的事件的更多信息，请参阅[此处](https://github.com/nuxt/telemetry)。
