# globalName 属性

Nuxt 允许自定义主 HTML 模板中使用的全局 ID、主 Vue 实例名称及其他选项。

---

- 类型: `String`
- 默认值: `nuxt`

```js{}[nuxt.config.js]
{
  globalName: 'myCustomName'
}
```

::alert{type="warning"}
`globalName` 必须是有效的 JavaScript 标识符，更改它可能会导致依赖 Nuxt 命名函数的某些插件失效。如果只想更改显示的 `__nuxt` HTML ID，请使用 `globals` 属性。
::

## globals 属性

> 自定义基于 `globalName` 的特定全局名称。

- 类型: `Object`
- 默认值:

```js{}[nuxt.config.js]
globals: {
  id: globalName => `__${globalName}`,
  nuxt: globalName => `$${globalName}`,
  context: globalName => `__${globalName.toUpperCase()}__`,
  pluginPrefix: globalName => globalName,
  readyCallback: globalName => `on${_.capitalize(globalName)}Ready`,
  loadedCallback: globalName => `_on${_.capitalize(globalName)}Loaded`
},
```
