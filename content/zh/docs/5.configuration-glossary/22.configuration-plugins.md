# plugins 属性

使用 Nuxt 的 plugins 选项使用 Vue.js 插件。

---

**注意**：从 Nuxt 2.4 起，引入了 `mode` 作为 `plugins` 的选项来指定插件类型，可选值为 `client` 或 `server`。`ssr: false` 将在下一个主要版本中随 `mode: 'client'` 的改进而废弃。

- 类型: `Array`
  - 元素: `String` 或 `Object`

元素为对象时，属性如下：

- src: `String`（文件路径）
- mode: `String`（`client` 或 `server`）_如果定义，文件只会包含在相应（客户端或服务端）一侧。_

**注意**：旧版本

- 类型: `Array`
  - 元素: `String` 或 `Object`

元素为对象时，属性如下：

- src: `String`（文件路径）
- ssr: `Boolean`（默认为 `true`）_如果为 false，文件只会在客户端包含。_

> plugins 属性可以轻松地将 Vue.js 插件添加到主应用程序中。

```js{}[nuxt.config.js]
export default {
  plugins: [
    { src: '~/plugins/both-sides.js' },
    { src: '~/plugins/client-only.js', mode: 'client' },
    { src: '~/plugins/server-only.js', mode: 'server' }
  ]
}
```

```js{}[nuxt.config.js]
export default {
  plugins: ['@/plugins/ant-design-vue']
}
```

```js{}[plugins/ant-design-vue.js]
import Vue from 'vue'
import Antd from 'ant-design-vue'
import 'ant-design-vue/dist/antd.css' // 按照 Ant Design 文档

Vue.use(Antd)
```

注意 css 是[按照 Ant Design 文档导入的](https://vue.ant.design/docs/vue/getting-started/#3.-Use-antd's-Components 'External tip relevant to building plugins')。

`plugins` 属性中定义的所有路径都会在主应用程序初始化之前**导入**。
