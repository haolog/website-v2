# buildDir 属性

定义 Nuxt 应用程序的 dist 目录。

---

- 类型: `String`
- 默认值: `.nuxt`

```js{}[nuxt.config.js]
export default {
  buildDir: 'nuxt-dist'
}
```

由于默认名称以点开头，许多工具会将 `.nuxt` 视为隐藏目录。使用此选项可以避免这种情况。
