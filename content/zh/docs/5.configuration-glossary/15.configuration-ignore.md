# ignore 属性

为 Nuxt 应用程序定义要忽略的文件

---

## .nuxtignore

可以使用 `.nuxtignore` 文件让 Nuxt 在构建时忽略项目根目录（`rootDir`）中的 `layout`、`page`、`store` 和 `middleware` 文件。`.nuxtignore` 文件遵循与 `.gitignore` 和 `.eslintignore` 相同的规范，每行是一个表示要忽略文件的 glob 模式。

示例：

```
# 忽略 foo.vue 布局
layouts/foo.vue
# 忽略文件名以 -ignore.vue 结尾的布局
layouts/*-ignore.vue

# 忽略 bar.vue 页面
pages/bar.vue
# 忽略 ignore 文件夹中的页面
pages/ignore/*.vue

# 忽略 baz.js store
store/baz.js
# 忽略匹配 *.test.* 的 store 文件
store/ignore/*.test.*

# 忽略 foo 文件夹中除 foo/bar.js 外的中间件文件
middleware/foo/*.js
!middleware/foo/bar.js
```

> 有关规范的更多详情，请参阅 [gitignore 文档](https://git-scm.com/docs/gitignore)

## ignorePrefix 属性

- 类型: `String`
- 默认值: `'-'`

> pages/、layouts/、middleware/ 和 store/ 目录中，文件名以 `ignorePrefix` 属性指定的前缀开头的文件在构建时会被忽略。

默认情况下，所有以 `-` 开头的文件（如 `store/-foo.js` 和 `pages/-bar.vue`）都会被忽略。这样可以在不将其转换为路由、store 等的情况下，将测试、工具和组件等文件与调用者放在同一位置。

## ignore 属性

- 类型: `Array`
- 默认值: `['**/*.test.*', '**/*.spec.*']`

> 比 `ignorePrefix` 更可定制：所有匹配 `ignore` 中指定 glob 模式的文件在构建时都会被忽略。

## ignoreOptions

`nuxtignore` 内部使用 `node-ignore`，`ignoreOptions` 可以作为 `node-ignore` 的 `options` 进行配置。

```js{}[nuxt.config.js]
export default {
  ignoreOptions: {
    ignorecase: false
  }
}
```
