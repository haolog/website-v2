# 静态站点生成

使用静态站点生成，可以在构建阶段渲染应用程序，并部署到 Netlify、GitHub Pages、Vercel 等静态托管服务。这意味着部署应用程序不需要服务器。

---
### 生成站点

使用 [`target:static`](/docs/features/deployment-targets#static-hosting) 部署站点时，所有 `.vue` 页面都会生成为 HTML 和 JavaScript 文件。所有 API 调用都会被缓存到生成内容中名为 static 的文件夹中，这样客户端导航时就不需要再调用 API。

### 步骤 1：浏览器到 CDN

浏览器发送第一个请求时，会到达 CDN。

### 步骤 2：CDN 到浏览器

CDN 将已生成的 HTML、JavaScript 和静态资源发送回浏览器。内容显示出来，Vue.js 水合生效使其变为响应式。此过程之后，页面变为可交互状态。

### 步骤 3：浏览器到浏览器

页面间导航通过 [`<NuxtLink>`](/docs/features/nuxt-components#the-nuxtlink-component) 在客户端完成，因此不会再次访问 CDN。即使硬刷新浏览器，所有 API 调用也会从已缓存的静态文件夹中加载。

### SPA 回退

使用 `generate.exclude` 属性从生成中排除的页面将回退为单页应用程序，因此这些页面不存在于 CDN 中，当用户导航到这些页面时，将在客户端浏览器中渲染。

::alert{type="next"}
要深入了解，请参阅 [generate 属性](/docs/configuration-glossary/configuration-generate#exclude)。
::

### 更新内容

要从 API 获取新内容，需要重新生成站点。大多数静态站点托管提供商允许通过 git 命令或拉取请求将更改推送到 master 分支来触发重新生成。

### 预览模式

预览模式会调用 API 或 CMS，以便在部署前实时查看更改。有关如何启用此功能，请参阅[预览模式](/docs/features/live-preview)。
