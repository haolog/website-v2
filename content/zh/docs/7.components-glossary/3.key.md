# key 属性

为内部的 `<router-view>` 组件设置 `key` 属性

---

- **类型:** `String` 或 `Function`

`key` 属性会传递给 `<router-view>`，用于动态页面的路由过渡。key 不同时，页面组件会重新渲染。

还有其他设置 key 的方式，详情请参阅 [nuxt 组件](/docs/features/nuxt-components)的 `nuxtChildKey` 属性。

```js
export default {
  key(route) {
    return route.fullPath
  }
}
```
