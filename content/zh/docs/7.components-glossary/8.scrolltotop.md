# scrollToTop 属性

`scrollToTop` 属性用于指定在渲染页面前是否滚动到顶部。

---

- **类型:** `Boolean`（默认: `false`）

Nuxt 的默认行为是：切换到其他页面时滚动到顶部，但有子路由时保持滚动位置。如果想在渲染子路由时也滚动到顶部，请将 `scrollToTop` 设为 `true`：

```html
<template>
  <h1>My child component</h1>
</template>

<script>
  export default {
    scrollToTop: true
  }
</script>
```

反之，父路由也可以手动将 `scrollToTop` 设为 `false`。

如果想覆盖 Nuxt 关于滚动的默认行为，请参阅 [scrollBehavior 选项](/docs/configuration-glossary/configuration-router#scrollbehavior)。
