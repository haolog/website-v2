# watchQuery 属性

监听查询字符串，变化时执行组件方法（asyncData、fetch、validate、layout 等）

---

- **类型:** `Boolean` 或 `Array` 或 `Function`（默认: `[]`）

设置 `watchQuery` 键，指定要监听的查询字符串。定义的字符串发生变化时，所有组件方法（asyncData、fetch、validate、layout 等）都会被调用。为提升性能，默认禁用监听。

如果想对所有查询字符串设置监听，请设置 `watchQuery: true`。

```js
export default {
  watchQuery: ['page']
}
```

也可以使用 `watchQuery(newQuery, oldQuery)` 函数进行更精细的监听。

```js
export default {
  watchQuery(newQuery, oldQuery) {
    // 仅当旧查询字符串包含 `bar` 且新查询字符串包含 `foo` 时才执行组件方法
    return newQuery.foo && oldQuery.bar
  }
}
```

::alert{type="warning"}
**警告**：
v2.12 引入的新 `fetch` 钩子不受 `watchQuery` 影响。详情请参阅[监听查询字符串变化](/docs/features/data-fetching#the-fetch-hook)。
::
