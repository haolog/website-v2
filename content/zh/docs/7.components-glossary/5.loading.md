# loading 属性

loading 属性提供了为特定页面禁用默认加载进度条的选项。

---

- **类型:** `Boolean`（默认: `true`）

默认情况下，Nuxt 在路由间切换时会使用自带的组件显示进度条。

除了可以通过[加载选项配置](/docs/configuration-glossary/configuration-loading)全局禁用或自定义外，还可以通过将特定页面的 `loading` 属性设为 `false` 来禁用：

```html
<template>
  <h1>My page</h1>
</template>

<script>
  export default {
    loading: false
  }
</script>
```
