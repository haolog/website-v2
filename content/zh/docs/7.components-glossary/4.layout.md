# layout 属性

layouts 目录（第一层级）中的文件会成为自定义布局，可通过页面组件的 layout 属性指定使用。

---

- **类型:** `String` 或 `Function`（默认: `'default'`）

在页面组件中使用 `layout` 键来指定要使用的布局：

```js
export default {
  layout: 'blog',
  // 或
  layout(context) {
    return 'blog'
  }
}
```
