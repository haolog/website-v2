# 静态目录

`static` 目录直接映射到服务器根目录，包含可能不会更改的内容文件。所有包含的文件都由 Nuxt 自动提供，可从项目根 URL 访问。

---

`/static/robots.txt` 可在 `http://localhost:3000/robots.txt` 访问

`/static/favicon.ico` 可在 `http://localhost:3000/favicon.ico` 访问

此选项适用于 `robots.txt`、`sitemap.xml`、`CNAME`（对 GitHub Pages 部署很重要）等文件。

::alert{type="warning"}
此目录不能在没有额外配置的情况下重命名。
::

## 静态资源

如果不想使用 `assets` 目录的 webpack 资源，可以将图片添加到 static 目录。

在代码中可以以根目录（`/`）为基准引用这些文件：

```html
<!--来自 static 目录的静态图片-->
<img src="/my-image.png" />

<!--来自 assets 目录的 webpack 打包图片-->
<img src="~/assets/my-image-2.png" />
```

::alert{type="info"}
Nuxt 不会更改此路径，因此如果自定义了 `router.base`，需要手动添加路径。例如：

```html
<img :src="`${yourPrefix}/my-image.png`" />
```
::

## 静态目录配置

如有需要，可以在 `nuxt.config.js` 文件中配置 `static/` 目录的行为。

### 静态资源前缀

将 Nuxt 部署到子文件夹时（如 `/blog/`），router base 默认会添加到静态资源路径中。如果想禁用此行为，可以在 `nuxt.config.js` 中将 `static.prefix` 设为 false。

```js
export default {
  static: {
    prefix: false
  }
}
```

默认：`/blog/my-image.png`

禁用 `static.prefix` 后：`/my-image.png`
