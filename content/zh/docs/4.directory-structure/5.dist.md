# 分发目录

`dist` 是 *distribution* 的缩写。dist 文件夹在使用 `nuxt generate` 命令时动态生成。dist 文件夹包含静态生成的 Nuxt 应用程序部署和运行所需的生产 HTML 文件和资源。

---

### 部署

这是**静态托管**需要上传的文件夹，包含生产 HTML 文件和资源。

::alert{type="warning"}
`dist` 目录不应提交到版本控制系统。每次运行 `nuxt generate` 时都会自动生成，请在 `.gitignore` 中忽略它。
::

### dir 属性

dist 文件夹默认名为 dist，但可以在 nuxt.config 文件中配置。

```js{}[nuxt.config.js]
generate: {
  dir: 'my-site'
}
```

::alert{type="warning"}
如果更改 dist 文件夹的名称，需要将其添加到版本控制中以便 git 忽略它。
::

### subFolders 属性

Nuxt 默认将所有生成的页面放在文件夹中，但可以通过修改 nuxt.config 文件将 subFolders 设为 false 来更改此行为。

```js{}[nuxt.config.js]
generate: {
  subFolders: false
}
```

### fallback 属性

部署站点时，需要确保正确设置回退 html 路径，需要将其设置为错误页面，以便未知路由通过 Nuxt 渲染。如果未设置，Nuxt 会使用默认值 200.html。

运行单页应用程序时，由于不会生成其他路由，只需要 200.html 文件，使用它更合理。

对于静态生成的页面，建议使用 404.html 作为错误页面。

::alert{type="warning"}
根据托管服务，可能需要使用 200.html 或 404.html。请向托管提供商确认。例如 Netlify 使用 404.html。
::

```js{}[nuxt.config.js]
export default {
  generate: {
    fallback: '404.html'
  }
}
```

### excludes 属性

使用 generate 的 excludes 属性可以排除要生成的页面。这些页面不会生成为静态页面，而是回退到单页应用程序，仅在客户端渲染。

```js{}[nuxt.config.js]
generate: {
  exclude: [/admin/]
}
```

::alert{type="info"}
也可以使用正则表达式排除以特定单词开头或结尾的页面。
::
