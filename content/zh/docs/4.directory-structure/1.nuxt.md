# Nuxt 构建目录

`.nuxt` 目录即所谓的_构建目录_。该目录是动态生成的，默认情况下是隐藏的。目录中包含使用 `nuxt dev` 时自动生成的文件，以及使用 `nuxt build` 时的构建产物。修改这些文件非常适合调试，但请记住，这些都是生成的文件，再次运行 `dev` 或 `build` 命令时，这里保存的所有内容都会被重新生成。

---

::alert{type="warning"}
`.nuxt` 目录不应提交到版本控制系统。运行 `nuxt dev` 或 `nuxt build` 时会自动生成，请在 `.gitignore` 中忽略它。
::

### buildDir 属性

默认情况下，`.nuxt` 目录名以点开头，许多工具会将其视为隐藏目录。可以使用 buildDir 选项来避免这种情况。如果更改了名称，请记得将新名称添加到 `.gitignore` 文件中。

```js{}[nuxt.config.js]
export default {
  buildDir: 'nuxt-dist'
}
```

### .nuxt 文件夹内容：

- router.js 文件是 Nuxt 在 pages 文件夹中放置 `.vue` 文件时生成的路由文件。可以用于调试，查看 vue-router 生成的路由或查找特定路由的名称。
- router.scrollBehavior.js 是路由器的 ScrollBehavior。
  components 文件夹包含 NuxtChild 和 NuxtLink 等 Nuxt 组件，还包含 nuxt-build-indicator（应用程序构建期间显示的页面）和 nuxt-loading（等待页面加载时显示的加载组件），以及包含 Nuxt 默认错误页面的 nuxt-error 页面。
- mixins 文件夹包含 Nuxt `$fetch` 方法所需的文件。
- views 文件夹包含应用程序模板和服务器错误页面。
- app.js 是主应用程序文件。
- client.js 文件是客户端文件，处理客户端发生的所有事情。
- empty 文件是故意留空的，用于不处理任何内容的别名。
- index.js 文件启动应用程序。
- loading.html 是页面加载时使用的文件。
- middleware 文件是中间件存储的地方。
- server.js 文件是在服务器上运行的所有代码。
- utilities 包含 Nuxt 运行所需的工具。

### 部署

`.nuxt` 文件夹是 SSR 应用程序部署所需文件的一部分。但静态 Nuxt 应用程序的部署使用 `dist` 文件夹，因此不需要它。
