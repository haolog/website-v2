# 将 Nuxt 部署到 Vercel

如何将 Nuxt 应用部署到 Vercel？

---

## 通过 Vercel 部署静态站点

在 Vercel 上部署静态站点无需任何配置。Vercel 会检测到您正在使用 Nuxt，并为您的部署启用正确的配置。更多详情请参阅 [Vercel 指南](https://vercel.com/guides/deploying-nuxtjs-with-vercel)。

## 通过 Vercel 部署 SSR

Nuxt 团队和贡献者创建了官方 [@nuxtjs/vercel-builder](https://github.com/nuxt/vercel-builder) 包，用于在 [Vercel](https://vercel.com) 上部署无服务器 Nuxt 运行时。

您只需设置 `vercel.json` 文件：

```json
{
  "builds": [
    {
      "src": "nuxt.config.js",
      "use": "@nuxtjs/vercel-builder",
      "config": {}
    }
  ]
}
```

更多详情请参阅[文档](https://github.com/nuxt/vercel-builder)。

### 通过 Nuxt PWA 模块使用 Service Worker

为避免 Service Worker 出现 404 错误，请确保在路由配置中包含 `sw`。

```json
{
  "version": 2,
  "builds": [
    {
      "src": "nuxt.config.js",
      "use": "@nuxtjs/vercel-builder",
      "config": {
        "serverFiles": ["package.json"]
      }
    }
  ],
  "routes": [
    {
      "src": "/sw.js",
      "continue": true,
      "headers": {
        "Cache-Control": "public, max-age=0, must-revalidate",
        "Service-Worker-Allowed": "/"
      }
    }
  ]
}
```

更多详情请参阅 https://github.com/nuxt/vercel-builder。
