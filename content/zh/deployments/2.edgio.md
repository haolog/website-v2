# 如何在 Edgio 上部署 Nuxt

如何在 Edgio 上部署 Nuxt 应用？

---

Edgio 同时支持静态和通用（SSR）Nuxt 应用。

[Edgio Applications](https://docs.edg.io) 是一个互联网规模的平台，帮助团队轻松构建、发布、保护和加速 Web 应用及 API。

详细步骤请参阅 [Edgio 的 Nuxt 集成指南](https://docs.edg.io/guides/nuxt)。

## 开始

1. 注册 Edgio [免费账户](https://app.layer0.co/signup)

2. 安装 [Edgio CLI](https://docs.edg.io/guides/cli)

::code-group
```bash [Yarn]
yarn global add @edgio/cli
```
```bash [NPM]
npm i -g @edgio/cli
```
::

3. 更新 `nuxt.config.*`，在 `buildModules` 中添加 `@edgio/nuxt/module`：

```js
buildModules: [['@edgio/nuxt/module', { edgioSourceMaps: true }]],
```

4. 运行 `edgio init`，为 Edgio 配置您的项目。

## 在 Edgio 上运行项目

在项目目录中运行以下命令，在本地开发模式下测试应用：

```bash
edgio dev
```

在项目目录中运行以下命令，在本地生产模式下测试应用：

```bash
edgio build && edgio run --production
```

## 部署到 Edgio

在项目目录中运行以下命令部署应用：

```bash
edgio deploy
```

## 获取帮助

如果遇到问题，请查看指南中的[故障排除部分](https://docs.edg.io/guides/nuxt#section_troubleshooting)，或在 [Edgio 论坛](https://forum.edg.io)中创建工单。
