# 懒加载组件

在组件中使用 fetch 从 API 获取数据，以及组件的自动导入和懒加载。

---

本示例中：

`components/MountainsList.vue` 使用 fetch 从 API 获取数据。

- `$fetchState.pending` 在等待数据加载时显示加载消息。
- `$fetchState.error` 用于在组件无法加载时显示错误消息。

`pages/index.vue` 展示如何通过在组件前加"Lazy"前缀来懒加载组件。

`nuxt.config.js` 展示 `components: true`，用于自动导入组件。
