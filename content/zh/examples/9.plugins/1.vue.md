# Vue 插件

本示例展示如何向应用程序添加 Vue 插件

---

本示例中：

`plugins/vue-tooltip.js` 导入 tooltip 并告知 Vue 使用它。

`pages/index.vue` 使用该插件。

`nuxt.config.js` 包含用于注册插件的 `plugins` 属性和用于添加 tooltip CSS 的 `css` 属性。

`package.json` 显示 tooltip 包已安装。
