# 外部包插件

本示例展示如何使用外部包 axios 作为插件

---

本示例中：

`plugins/axios.js` 使用 `onError()` 函数拦截 `$axios` 调用。

`pages/index.vue` 使用 `$axios` 从 API 获取数据。

`pages/mountains/_slug.vue` 使用 `$axios` 从 API 获取数据，并从路由参数获取 ID。

`pages/404.vue` 是发生错误时调用的页面。

`nuxt.config.js` 包含用于注册模块和插件的 `module` 属性和 `plugin` 属性。

`package.json` 显示我们的模块 `@nuxtjs/axios` 已安装。
