# 自定义插件

本示例介绍如何创建自己的插件

---

本示例中：

`plugins/hello.js` - 向控制台记录动态消息。

`store/index.js` - 存储输入的动态消息。

`pages/index.vue` 使用 hello 插件：

- 挂载时向控制台记录消息。
- 向控制台记录包含输入值的消息。

`plugins/nuxt-api.js` - 从我们的 API 获取数据。

`pages/api-plugin.vue` - 使用插件从 API 获取并显示数据。

`nuxt.config.js` - 使用 `plugins` 属性注册插件。
