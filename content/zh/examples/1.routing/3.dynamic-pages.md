# 动态页面

使用动态页面从 API 获取数据并添加到这些页面

---

本示例中：

`pages/_slug.vue` 展示从路由参数获取的数据。

`pages/index.vue` 从 API 获取山脉列表。

`pages/_continent/_mountain.vue` 展示每个大洲中每座山的详情页面。
