# webpack 资源

使用 assets 文件夹向应用程序添加 CSS、图片和字体

---

本示例中：

`pages/index.vue` 展示：

- 如何从 assets 文件夹添加图片。
- 如何使用 CSS 从 assets 文件夹添加背景图片。
- 如何使用 data 属性从 assets 文件夹添加动态图片。

`nuxt.config.js` 包含用于全局添加 CSS 文件的 `css` 属性。

`assets/main.css` 展示如何使用 `@font-face` 规则从 assets 文件夹引用 DMSans 字体。
